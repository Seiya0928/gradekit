How it works

How to calculate it

Divide the number of correct answers by the total number of questions, then multiply by 100. The letter label uses a common U.S. plus/minus scale.

Test percentage = (correct answers ÷ total questions) × 100

Worked example

Example calculation

If 46 answers are correct on a 50-question test, 46 ÷ 50 × 100 = 92%, typically an A−.

Use the calculator above to substitute your own numbers. Results update immediately.

Before you rely on the number

Things worth checking

  • This page assumes every question is worth the same number of points. Mixed point values need the percentage grade calculator.
  • Teachers grading a full stack of papers usually want the EZ Grader, which prints one chart covering every possible number wrong.
  • If the test was curved, run the raw score through the grade curve calculator before reading the letter grade.

Common questions

Test Grade Calculator FAQ

How do I calculate from wrong answers instead?

Subtract wrong answers from total questions to find correct answers, or use the EZ Grader page.

Does every question have equal value?

This calculator assumes equal points per question. For questions with different point values, use the grade calculator.

Can teachers use this calculator?

Yes. For a full score chart covering every possible number wrong, use EZ Grader.
